# Самовзятие инцидентов (KAN-85)

Клиент использует `taskId` открытой задачи из очереди KAN-24, а не номер INC.
Общий префикс — `/api/dashboard/coordination-tasks`. Для всех запросов нужен
Bearer JWT активного координатора; идентификатор координатора берётся из текущей
сессии, а не из запроса.

| Запрос | Результат `200` |
| --- | --- |
| `POST /{taskId}/claim` | Зафиксировать владельца из обычной очереди; повтор от владельца возвращает ту же задачу. |
| `GET /mine` | Массив открытых задач текущего координатора. |
| `POST /{taskId}/fullscreen-window` | При показе активного P4 без владельца вернуть `{ "windowId": "<uuid>", "expiresAt": "<UTC>" }`. Для других приоритетов или уже взятой этим координатором задачи — оба поля `null`. |
| `POST /{taskId}/fullscreen-window/{windowId}/accept` | Взять задачу, если окно принадлежит текущему координатору и ещё открыто. |

`claim`, `accept` и элементы `mine` возвращают `taskId`, `incidentId`,
`coordinatorId`, `acceptedAt`. Только принятие в полноэкранном окне заполняет
`acceptedAt` (UTC ISO 8601). Никаких изменений назначения в ITSM эти запросы не делают.

Полноэкранный UI вызывает `fullscreen-window` в момент показа, и только вне
мониторинга / большого дашборда. Обычный claim таймер не запускает. Срок вычисляется
от первого серверного подтверждения показа: +60 секунд. Повторный показ той же
задачи тому же координатору не сдвигает `expiresAt`, в том числе после рестарта.
Клиент должен считать окно истёкшим при `now >= expiresAt`. При истечении задача
остаётся в общем пуле для обычного claim; переназначения и исключения координатора нет.

Показ не резервирует задачу. У разных зрителей свои окна, но владелец может быть
только один. Повтор `accept` успешного владельца в пределах его окна не меняет
`acceptedAt`. Операция «Увидел» (`POST /api/dashboard/shift/events/ack`) не принимает
задачу и не меняет её владельца.

| Статус | Код ошибки |
| --- | --- |
| `404` | `COORDINATION_TASK_NOT_OPEN` — задача отсутствует или закрыта. |
| `409` | `COORDINATION_TASK_TAKEN` — задача закреплена за другим координатором. |
| `409` | `COORDINATION_WINDOW_UNAVAILABLE` — окно не выдано этому координатору или задача больше не подходит. |
| `409` | `COORDINATION_WINDOW_EXPIRED` — срок уже истёк, включая момент `expiresAt`. |
